# Pashu Saathi · पशु साथी

A mobile-first, Hindi and English farm register for livestock owners and veterinary workers. Open `index.html` in a modern browser to try the fictional Rampur demo farm. No installation is needed.

Animals, records and local profiles are saved in this browser. Reminders appear inside the app. The demo does not send SMS, synchronize devices, or provide veterinary treatment recommendations. Download a backup from Settings before clearing browser data.
